# Bolos Artesanais

Landing page desenvolvida para apresentar um negócio local de **bolos artesanais**.

Este projeto foi criado como **exercício de desenvolvimento front-end**, simulando o site de uma pessoa da minha cidade que produz bolos artesanais e ainda não possui presença online.

A página foi pensada para mostrar os produtos, explicar o diferencial dos bolos feitos à mão e facilitar o contato para encomendas.

⚠️ O projeto foi feito **apenas para fins de aprendizado**.

---

## Sobre o projeto

O site simula uma **landing page de confeitaria artesanal**, focada em apresentar os produtos de forma simples e incentivar clientes a realizarem pedidos.

A página foi estruturada para guiar o visitante desde a apresentação do negócio até o contato direto pelo **WhatsApp**.

---

## Seções da página

A landing page contém as seguintes seções:

### Header
Área superior com apresentação do site e um **Call To Action (CTA)** incentivando o visitante a conhecer os produtos ou fazer um pedido.

---

### Início
Seção de destaque com uma umagem de um bolo artesanal e um **CTA** para incentivar a navegação ou encomenda.

---

### Produtos
Área onde são exibidos alguns dos bolos oferecidos, com imagens ou descrições simples.

---

### Diferença: Industrial vs Feito à Mão
Seção explicando a diferença entre bolos **industrializados** e **artesanais**, apresentando:

- vantagens
- desvantagens
- características de cada tipo

O objetivo é destacar o valor do produto artesanal.

---

### Como encomendar
Explicação simples do processo de pedido, mostrando o passo a passo para que o cliente faça sua encomenda.

Exemplo de fluxo:

1. Escolher o sabor
2. Defina o peso
3. Retirada ou Entrega

---

### O que dizem os clientes
Área com depoimentos de clientes para gerar mais confiança no produto.

---

### Call To Action final
No final da página existe um **botão de contato direto via WhatsApp**.

Ao clicar, o botão:

- abre o WhatsApp
- já inicia uma conversa
- envia uma **mensagem automática pré-preenchida**

Isso facilita o contato rápido para encomendas.

---

## Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias básicas da web:

- **HTML5**
- **CSS3**

O botão de contato utiliza um **link direto para o WhatsApp com mensagem automática**.

---

## Objetivo do projeto

Este projeto foi desenvolvido para:

- Praticar **estruturação de landing pages**
- Melhorar habilidades em **HTML e CSS**
- Criar páginas para **negócios locais**
- Desenvolver projetos para **portfólio**
- Simular sites institucionais simples

---

## Status do projeto

Projeto criado apenas para **fins de aprendizado**.

O site contém apenas a **landing page**, sem:

- sistema de pedidos
- painel administrativo
- banco de dados
- backend
